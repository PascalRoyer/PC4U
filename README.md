# PC4U  Équipe 19

## Description du projet
PC4U est une application web développée dans le cadre du cours **INF1763 – Techniques et outils professionnels de développement logiciel** à l’Université du Québec en Outaouais.

L’objectif du projet est de concevoir une plateforme permettant aux utilisateurs de consulter des composants informatiques et de créer une configuration de PC personnalisée selon leurs besoins et leur budget. L’application simule un système de vente et de configuration de PC en ligne, intégrant une interface utilisateur, une logique serveur et une base de données.

---

## Fonctionnalités principales
- Création de compte utilisateur (inscription)
- Authentification sécurisée (login)
- Consultation des produits informatiques
- Affichage des prix et des caractéristiques techniques
- Configurateur de PC
- Ajout et suppression de produits dans le panier
- Gestion du panier utilisateur
- Sauvegarde et chargement de templates de configuration
- Communication avec une base de données

---

## Architecture
Le projet repose sur une architecture **client–serveur** composée de :
- un **frontend** pour l’interface utilisateur,
- un **backend** pour la logique métier et l’API REST,
- une **base de données SQL Server** pour le stockage des données.

Les échanges entre le frontend et le backend se font via des requêtes HTTP au format JSON.

## Étapes d’installation

1. Cloner le dépôt GitHub du projet sur votre machine.
2. Accéder au dossier principal du projet nommé **PC4U**.
3. Accéder au dossier **backend**.
4. Installer les dépendances nécessaires au backend.
5. Lancer le serveur backend.
6. Ouvrir le frontend :
   - soit en ouvrant le fichier **index.html** dans un navigateur,
   - soit en accédant à l’application via **http://localhost:8080** si le frontend est servi par Express.
